# Myntra Apparel Analysis

## Project Overview

Analyzed Myntra apparel data using Microsoft Excel to clean, transform, and analyze product information related to pricing, discounts, ratings, and size availability.

## Objectives

- Clean and prepare the dataset for analysis
- Standardize discount-related data
- Handle missing values and duplicate records
- Analyze product pricing, ratings, discounts, and size availability
- Perform product-level data lookups

## Tools & Skills

- Microsoft Excel
- Data Cleaning & Transformation
- XLOOKUP
- INDEX-MATCH
- AVERAGEIF
- IF
- Data Validation & Standardization

## Key Analysis

- Calculated average original price for highly rated products
- Identified products with discounts greater than 50%
- Analyzed product availability by size
- Classified products into High Discount and Low Discount categories
- Retrieved product details using XLOOKUP and INDEX-MATCH
